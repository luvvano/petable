## v2: Lossless round-trip неизвестных стадий конверта
- **What:** декодировать стадии чужих/будущих типов в сырой JSON-контейнер и сохранять без потерь.
- **Why:** как только у файла появится второй писатель (агент, стадия интервью), старая версия приложения без round-trip молча сотрёт чужую стадию при сохранении.
- **Pros:** безопасная эволюция формата. **Cons:** ~вечер возни с Codable-контейнером.
- **Context:** было добавлено в v1 инженерным ревью, вынесено в v2 решением T4 (один писатель/читатель сейчас; формат защищён полем `version`).
- **Depends on:** появление второго писателя файла. **Блокирует:** file-watch (выше).
- **НЕ блокирует новые секции конверта** (уточнено /plan-eng-review 2026-07-28). `Envelope.init(from:)` бросает `unsupportedVersion` для файла новее сборки (`Envelope.swift:145-147`, тест `EnvelopeTests.swift:20-21`) — старая сборка не «тихо съедает» незнакомую секцию, она **отказывается открыть файл**. Конверт прошёл v1→v10 без единой потери на дисциплине «добавил секцию — бампни версию». Реальная угроза остаётся только там, где файл правит кто-то помимо приложения: file-watch, ручная правка JSON, синк между машинами. Агент ходит через `AgentArtifactsPayload` в процессе, а не через файл.
