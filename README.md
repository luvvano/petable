# petable

Редактор графа работ (Jobs To Be Done) для macOS. Уровни — горизонтальные полосы, работы раскладываются слева направо автоматически; связи — внутри уровня (следующая работа) и на уровень ниже (декомпозиция). Документы — файлы `.petable` (JSON-конверт `{version, stages}`).

## Проекты

Проект = документ `.petable`; внутри проекта — несколько именованных графов работ (сайдбар: выбрать, «+ Новый граф», контекстное меню — переименовать/удалить). Хаб проектов (меню File → «Проекты…», ⇧⌘O) показывает проекты из `~/Documents/Petable`: создать, переименовать, открыть двойным кликом. Файлы, открытые из других мест, работают как обычные документы.

Формат: v3 — стадии конверта получили `id` и `name`. Старые файлы v1 (дерево) и v2 (одна безымянная стадия) читаются и мигрируют при сохранении.

## Требования

- macOS 14.0+
- Xcode 16+ (Swift 6.1)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) — только если меняете `project.yml`

## Установка с нуля

```bash
# 1. Клонировать
git clone <repo-url> petable
cd petable

# 2. (опционально) перегенерировать проект — нужно только после правок project.yml
brew install xcodegen
xcodegen generate

# 3. Открыть и запустить
open petable.xcodeproj   # схема petable, ⌘R
```

Или одной командой из терминала — Release-сборка, установка в `/Applications`, запуск:

```bash
make install
```

Другие цели: `make run` (сборка и запуск без установки), `make build`, `make test`, `make clean`.

## Тесты

```bash
# Юнит-тесты ядра (GraphCore: движок, раскладка, конверт, undo)
swift test

# UI-тесты (перехватывают фокус и клавиатуру — не запускать, пока работаете за машиной)
xcodebuild test -project petable.xcodeproj -scheme petable
```

## Структура

```
App/Sources/        — macOS-приложение (SwiftUI): оболочка с сайдбаром, канвас, документ
Sources/GraphCore/  — ядро (SPM-пакет): модель WorkGraph, интенты, раскладка, конверт файла
Tests/              — тесты GraphCore (swift-testing)
project.yml         — описание Xcode-проекта для XcodeGen
```

## Горячие клавиши канваса

| Клавиша | Действие |
|---|---|
| Tab | Связанная работа на уровень ниже |
| ⌘Return | Связанная работа справа (тот же уровень) |
| Return | Редактировать выделенную работу |
| ⌘← / ⌘→ | Сдвинуть работу внутри уровня |
| ← → ↑ ↓ | Навигация по работам |
| Delete | Удалить работу (⌘Z возвращает) |
| Esc | Снять выделение / отменить редактор |
| ⌘-скролл / пинч | Zoom вокруг курсора |
| Двухпальцевый скролл | Панорамирование |

Текст работы вводится грамматикой `роль: хочу …` — префикс до первого двоеточия становится ролью.
