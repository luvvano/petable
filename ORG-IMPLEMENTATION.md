## Правила, которые легко потерять

- Вердикт несёт ОТВЕТ сотрудника (JSON-блок), не события CLI; невалидный = failed.
- Возвраты: ревью+тесты+Reject — ОДИН счётчик, лимит 3 (`Engine.returnLimit`).
- Runtime НЕ в документе: только `RunSummary` идемпотентно по runID (П1′).
- Хранилище: `~/Library/Application Support/Petable` (T3), НЕ ~/Documents.
- Словарь UI: Принять/Вернуть, «возврат N из 3», «требует внимания», ≈$0.40.
- Коммиты — только по явной просьбе пользователя.
